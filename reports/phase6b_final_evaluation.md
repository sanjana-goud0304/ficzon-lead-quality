# Phase 6b: final test evaluation

_Generated by `scripts/run_final_eval.py`. Models and thresholds were frozen from train+validation (Apr-Sep 2018) in `reports/phase6_frozen_config.json` before the test months were loaded. Each model was refit once on all train+validation rows and scored once on the test months._

- Train+validation: 6,039 leads (2018-04-28 to 2018-09-30), High rate 36.7%
- Test: 1,383 leads (2018-10-01 to 2018-11-14), High rate 45.6% (a random scorer's PR-AUC and precision both equal this)
- Share of test leads still 'Open' (mapped to Low): 3.3%

## Reading the results

- creation_time ROC-AUC 0.559 vs Source-rate rule 0.545; intervals overlap.
- assignment_time ROC-AUC 0.764 vs post_contact 0.795; intervals overlap.
- Top-20% lift: creation_time 1.21, assignment_time 1.63, post_contact 1.74, Source-rate rule 1.18.
- Test base rate 45.6% vs 36.7% in train+validation: the label mix shifted, which moves threshold-based metrics.
